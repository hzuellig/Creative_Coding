don’t
touch please

Inter-Aktion: ein kurzer Dialog zwischen Körper, Kamera und Screen. Ihr zeigt dem Browser ein Zeichen, der Browser antwortet.

1Das Setting

Zeichen
Etwas, das man in die Kamera hält: ein Wort auf Papier, ein Blatt mit Punkten, ein gezeichneter Halbkreis, eine bemalte Hand.
Maschine
Ein Bildmodell, trainiert mit Teachable Machine. Es unterscheidet nur zwei Zustände: off (kein Zeichen) und on (euer Zeichen).
Antwort
Ein p5.js-Sketch. Er sagt etwas im Ruhezustand und etwas anderes, sobald das Zeichen erscheint. Er antwortet, ergänzt, widerspricht, bittet.
Handlung
Zeigen und Antworten zusammen ergeben eine kleine Szene. Sie wird aufgeführt, nicht nur vorgeführt.
Bezüge
Yehwan Song (widerständige, körperliche Interfaces), Fluxus Event Scores (knappe Handlungsanweisungen), Golan Levin, Opto Isolator, Naum June Paik, Participation TV.

2Scores Beispiele

Der Screen sagt: don’t.
Zeige ein Schild: touch.
Der Screen sagt: please.

Halte ein Blatt mit Punkten in die Kamera.
Die Punkte auf dem Screen beginnen zu tanzen.

Zeige einen Halbkreis.
Der Screen zeichnet die andere Hälfte.

Fragt euch: Was sagt der Browser, solange niemand etwas zeigt? Und wer hat am Ende das letzte Wort, ihr oder die Maschine?

3Vorbereitung

  1. Stellt das Zeichen her. Schreibt, zeichnet, schneidet, klebt. Buchstaben und Formen mindestens 5 cm hoch, kräftige Kontraste.
  2. Stellt den Laptop so auf, dass die Kamera in den Raum schaut und der Hintergrund ruhig bleibt.
  3. Trainiert im selben Raum, bei demselben Licht, in dem ihr später auftretet. Das Modell lernt den Raum mit.

4Projekt anlegen

  1. Öffnet teachablemachine.withgoogle.com/train. Chrome oder Firefox verwenden.
  2. Wählt Image Project und dann Standard image model.
  3. Es erscheinen zwei Klassen. Das reicht.
  4. Benennt die Klassen um (auf den Stift neben dem Namen klicken). Schreibt die Namen exakt so, klein und ohne Leerzeichen:
Klassenname Was im Bild ist
off Raum ohne Zeichen. Auch Menschen, die herumgehen, winken, nah an die Kamera kommen, leere Hände zeigen.
on Euer Zeichen im Bild: nah und fern, gerade und schräg, von verschiedenen Personen gehalten.

Diese Namen werden später im p5-Code verglichen. Ein Tippfehler bedeutet: der Sketch reagiert nicht.

5Bilder aufnehmen

  1. Klickt in einer Klasse auf Webcam. Der Browser fragt nach Kamerazugriff: erlauben.
  2. Das Zahnrad neben Hold to Record öffnet die Einstellungen. Empfohlen: Hold to record ausschalten, Delay 3 Sekunden, Duration 8 Sekunden. So hat die Person vor der Kamera beide Hände frei.
  3. Nehmt pro Klasse 200–400 Bilder auf, in mehreren kurzen Durchgängen. Beide Klassen sollten ungefähr gleich viele Bilder haben.

Variation ist das Training

Das Modell lernt nur, was ihr ihm zeigt. Innerhalb jeder Klasse variieren:

  • Position im Bild: links, rechts, oben, unten
  • Abstand: nah an der Linse und weiter weg
  • Winkel: gerade, gekippt, leicht gedreht
  • Wer das Zeichen hält: mehrere Personen, verschiedene Kleidung

off ist die wichtigere Klasse. Alles, was nicht euer Zeichen ist, gehört hierhin: Gesichter, Hände, leeres Papier, die Rückseite des Schilds. Sonst meldet das Modell on, sobald sich irgendetwas bewegt.

6Trainieren

  1. Klickt Train Model. Unter Advanced nichts ändern, die Standardwerte reichen (Epochs 50, Batch Size 16, Learning Rate 0.001).
  2. Während des Trainings den Tab nicht wechseln und den Laptop nicht zuklappen. Das Training pausiert sonst.
  3. Dauer: meist unter einer Minute.

7Testen

Rechts im Feld Preview läuft das Modell live. Die Balken zeigen die Sicherheit pro Klasse.

  1. Zeigt das Zeichen, nehmt es weg, zeigt es wieder. Springt der Balken sauber zwischen off und on?
  2. Testet ohne Zeichen, ganz nah an der Kamera, mit leeren Händen. Das Modell sollte off zeigen.

Wenn es nicht stimmt: gezielt Bilder in der falschen Klasse nachaufnehmen und neu trainieren. Siehe Fehlerbehebung.

8Exportieren und sichern

  1. Klickt Export Model, Reiter Tensorflow.js, Option Upload (shareable link), dann Upload my model.
  2. Kopiert den Link, der erscheint. Er sieht so aus: https://teachablemachine.withgoogle.com/models/XXXXXXX/
  3. Legt den Link in einer Textdatei ab. Ihr braucht ihn im p5-Sketch.
  4. Sichert das Projekt über das Menü oben links: Save project to Drive oder Download project as file. Nur so könnt ihr später Bilder ergänzen und neu trainieren.

Nach jedem Neutraining muss neu hochgeladen werden. Der Link bleibt gleich, wenn ihr im selben Projekt bleibt, trotzdem kurz prüfen.

9Übergabe an p5.js

Ein minimaler Dialog: im Ruhezustand sagt der Screen don’t, beim Zeichen please. In index.html muss ml5 eingebunden sein: <script src="https://unpkg.com/ml5@1/dist/ml5.min.js"></script>

let classifier;
let video;
let label = "off";
const modelURL = "https://teachablemachine.withgoogle.com/models/XXXXX/";

async function setup() {
  createCanvas(windowWidth, windowHeight);
  video = createCapture(VIDEO);
  video.size(640, 480);
  video.hide();
  classifier = await ml5.imageClassifier(modelURL + "model.json");
  classifier.classifyStart(video, gotResult);
}

function gotResult(results) {
  label = results[0].label;
}

function draw() {
  background(255);
  fill(0);
  textAlign(CENTER, CENTER);
  textSize(160);

  if (label === "on") {
    text("please", width / 2, height / 2);
  } else {
    text("don't", width / 2, height / 2);
  }
}

Variante: Halbkreis ergänzen

Nur draw() austauschen. Ohne Zeichen bleibt der Screen leer, beim Zeichen wächst die fehlende Hälfte.

let grow = 0; // 0 = nichts, 1 = ganzer Halbkreis

function draw() {
  background(255);
  noFill();
  stroke(0);
  strokeWeight(12);

  if (label === "on") {
    grow = min(grow + 0.02, 1);
  } else {
    grow = max(grow - 0.05, 0);
  }

  arc(width / 2, height / 2, 400, 400, -HALF_PI, -HALF_PI + PI * grow);
}

Von hier aus ist der Screen eure Bühne: Wie antwortet er? Zögert er, flüstert er, zittert die Schrift, weigert er sich einmal?
